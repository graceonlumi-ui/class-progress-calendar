# 🏫 교실 전자칠판용 스마트 학급알리미 (Class Board)

교실 전자칠판(대형 TV / 터치 모니터)에 항상 띄워두고 사용하는 **스마트 학급 대시보드 및 실시간 알림장 시스템**입니다.  
선생님이 교탁 PC나 개인 스마트폰으로 전달사항을 입력하면 전자칠판 화면에 **새로고침 없이 0.1초 만에 실시간으로 반영**됩니다.

---

## ✨ 주요 기능

### 1. 🕒 컴시간알리미 실시간 시간표 연동 (2학년 2반)
* 컴시간 서버와 직접 통신하여 당일 **우리 반의 최신 시간표**(1~7교시, 교사명)를 자동 표시합니다.
* **시간표 변경 감지**: 교체 수업, 결강, 보강 등 시간표가 변경된 경우 **노란색 하이라이트 카드 + `[시간표 변경]` 뱃지 + 원래 과목/교사 취소선**으로 시각적으로 명확하게 알려줍니다.
* **현재 교시 하이라이트**: 현재 수업 중인 교시를 자동으로 인식하여 푸른빛 네온 펄스 효과와 함께 표시합니다.

### 2. 🍱 나이스(NEIS) 오픈 API 오늘의 급식
* 교육부 나이스 공식 급식 식단 API를 연동하여 당일 **중식 메뉴, 칼로리(Kcal), 알레르기 유발 식품 번호**를 안내합니다.
* 주말, 공휴일, 방학 등 급식이 없는 날에는 친절한 대체 안내 문구를 표시합니다.

### 3. 📢 담임교사 전달사항 (실시간 알림장)
* 모바일/PC 관리자 화면에서 `[🚨 중요]`, `[📝 과제]`, `[🎒 준비물]`, `[📢 알림]`, `[🌱 한마디]` 카테고리별로 공지 등록.
* WebSocket 기술을 적용하여 선생님이 폰에서 "등록"을 누르면 **전자칠판 화면에 부드러운 애니메이션과 함께 즉각 등장**합니다.
* 상단 고정(PIN) 기능 지원.

### 4. 🧹 오늘의 청소 당번 (2가지 모드 동시 지원)
* **모드 A: 요일별 기본 순환 (자동)**
  * 월요일부터 금요일까지 요일별로 기본 배정된 모둠/학생이 자동으로 돌아갑니다.
* **모드 B: 오늘만 당번 직접 수정 (Override)**
  * 결석생이 있거나 특별 청소가 필요한 날, 선생님이 스마트폰으로 "오늘만 직접 수정"하여 이름/모둠을 입력하면 우선 반영됩니다.
  * 언제든지 "기본값 복귀" 버튼 하나로 다시 요일 기본 규칙으로 돌아갈 수 있습니다.

### 5. ⏱️ 원격 교실 타이머 & 긴급 알림
* **대형 타이머**: 선생님이 스마트폰에서 [3분], [5분], [청소 10분], [자습 20분] 버튼을 누르면 전자칠판에 대형 카운트다운 타이머가 작동합니다.
* **긴급 알림 팝업**: "모두 자리에 착석하세요!" 같은 전체 안내를 전자칠판 전체 화면에 띄울 수 있습니다.

### 6. 🎯 학급 D-Day & 실시간 디지털 시계
* 지필평가, 축제, 방학 등 학급 중요 일정을 D-Day로 카운트다운합니다.
* 1초 단위로 흐르는 선명한 시계와 오늘 날짜를 표시합니다.

## 🚀 빠른 시작 방법

1. **앱 폴더 열기**:
   * 바탕화면의 `My Apps/학급알리미` 폴더로 이동합니다.
2. **시작하기**:
   * **`시작하기.bat`** 파일을 더블 클릭합니다.
   * 자동으로 서버가 실행되고, 기본 웹 브라우저로 전자칠판 화면(`http://localhost:3000`)이 열립니다.
3. **전자칠판 전체화면**:
   * 키보드의 **`F11`** 키를 누르거나, 화면 우측 상단의 **전체화면 아이콘**을 클릭하면 군더더기 없는 완벽한 전체화면 대시보드가 됩니다.

---

## 📱 선생님 스마트폰 / 원격 접속 방법

1. 전자칠판 화면 우측 상단의 **`QR 코드`** 버튼을 누릅니다.
2. 스마트폰 카메라로 QR 코드를 스캔하거나, 스마트폰 브라우저에 표시된 관리자 주소(예: `http://172.2.xxx.xxx:3000/admin`)를 입력합니다.
3. **PIN 번호 입력**: 기본 비밀번호는 **`1234`** 입니다. (관리자 [학급설정] 탭에서 자유롭게 변경 가능)
4. 이제 교무실 컴퓨터나 스마트폰에서 자유롭게 전달사항을 올리고, 청소 당번을 바꾸고, 타이머를 켤 수 있습니다!

---

## ⚙️ 학급 및 학교 변경 방법

* 관리자 페이지(`/admin`)의 **[학급설정]** 탭에서:
  * 학교 검색창에 학교명을 입력하고 "검색"을 누르면 컴시간 코드와 나이스 코드가 자동으로 매핑됩니다.
  * 학년/반을 자유롭게 변경할 수 있습니다 (현재: 2학년 2반).
  * 학급 급훈 및 인사말, D-Day 일정을 편집할 수 있습니다.

│   └── appData.json     # 학급 설정, 공지사항, 청소당번, 디데이 저장 파일

    ├── admin.html       # 선생님 모바일/PC 반응형 원격 관리 페이지
    ├── css/
    │   └── style.css    # 글래스모피즘 & 애니메이션 스타일
    └── js/
        ├── board.js     # 전자칠판 화면 렌더링 및 웹소켓 수신 로직
        └── admin.js     # 관리자 조작 및 실시간 전송 로직
